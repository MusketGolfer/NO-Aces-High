# Community squadrons

Ace squadrons made by players, with their emblems, music and voice lines. They are not part of the mod and are not
included in releases.

## Installing one

1. Download the squadron's folder. (GitHub's **Code → Download ZIP** gets the whole repository; the folder is inside it.)
2. Put the folder in `BepInEx/config/NOAcesHigh/Squadrons/` in your game folder.
3. If the squadron flies an add-on aircraft or wears a Steam Workshop livery, install that too (its `squadron.json`
   names the aircraft and livery).
4. In the game, **F1 → NO Aces High → 4. Squadrons** lists it.
